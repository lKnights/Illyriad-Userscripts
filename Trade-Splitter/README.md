# Illyriad Trade Splitter

A userscript for Illyriad that makes it easy to divide caravan capacity between multiple resources using custom percentages.

## Features

- Split caravan capacity by percentage
- Select Wood, Clay, Iron, Stone, and Food
- Automatically distribute percentages equally
- Save and load custom presets
- Remembers settings between sessions
- Movable interface
- Designed to work directly with Illyriad

## Status

Currently in development.
