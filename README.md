# Illyriad Userscripts

A collection of userscripts and quality-of-life tools for [Illyriad](https://elgea.illyriad.co.uk/).

These scripts are designed to add useful features and improve existing parts of the Illyriad interface without changing the core game.

## Scripts

### Trade Splitter

A trade utility that makes it easy to divide caravan capacity between selected resources.

**Features:**
- Split caravan capacity using custom percentages
- Select Wood, Clay, Iron, Stone, and Food
- Automatically divide percentages equally
- Save and load custom presets
- Remembers settings between sessions
- Movable interface

**Status:** In development

### Sovereignty Claim Timer

Tracks sovereignty claim timing across multiple towns so you can easily see when a town is ready to claim a square.

**Planned features:**
- Track multiple towns at once
- Save timers between sessions
- Display source town and target square
- Countdown until the square can be claimed
- Highlight timers when they are ready

**Status:** In development

## Installation

These scripts require a userscript manager such as Tampermonkey, Violentmonkey, or a compatible userscript extension.

Individual installation instructions will be provided with each script.

## Compatibility

Designed for:

- Illyriad
- Desktop browsers with a compatible userscript manager

Mobile compatibility may vary depending on the userscript manager being used.
